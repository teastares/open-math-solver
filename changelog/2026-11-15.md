# 2026-11-15 变更记录

[返回变更记录索引](readme.md)

## 内点法进入正式构建

- 类型为生产集成。为统一生产和实验实现，将稀疏内点法的联立方向、能量计算和向量更新接入 [正式求解入口](../src/ipm.cpp)，原 [实验入口](../src/experimental/ipm.cpp) 改为转发。影响内点法内核、构建及旧实验入口。验证通过 IPM 公共接口、内部内核和独立联立核测试。

## 内点法衔接、诊断与计时

- 类型为功能与接口。为通过正式入口使用可选的预处理和交叉，将 [预处理](../include/solver/detail/ipm_presolve_state.hpp)、[IPX 交叉](../include/solver/detail/ipm_crossover_state.hpp)、[诊断](../include/solver/detail/ipm_diagnostics.hpp)和[分层计时](../include/solver/detail/ipm_profile.hpp)接入 [API 选项](../include/solver/ipm_options.hpp)及 [CLI](../src/main.cpp)。影响显式开启这些选项的 IPM 调用。验证通过 IPM 内核和 CLI 回归测试。

## 有界暖基对偶清理

- 类型为求解算法。为利用 crossover 提供的暖基增加可选的对偶 Phase II，正式 [暖基清理](../include/solver/detail/warm_cleanup.hpp) 使用完整对偶资格检查、两遍 Harris 比值和原模型终验。影响显式启用暖基对偶清理的齐次 IPM。验证通过 IPM 内核及 CLI 回归测试。

## 齐次内点法方向与旧因子尝试

- 类型为数值算法。为复用分解和控制不合格方向的影响，将 [旧因子状态](../include/solver/detail/factor_reuse_state.hpp)、[Schur 对角缩放](../include/solver/detail/schur_diagonal_transport.hpp)及[自然分母认证](../include/solver/detail/natural_schur.hpp)接入预测和校正，并在 [联立核](../include/solver/detail/ipm_coupled.hpp)中按五块归约真残差。影响齐次方向验算和显式启用的因子复用路径。验证通过 IPM 内核、联立核和 CLI 回归测试。

## 正规方程坐标与回代

- 类型为线性代数接口。为减少 KKT 到正规方程之间的向量搬运，在 [Normal 接口](../include/solver/detail/normal_cholesky.hpp)增加外部坐标回代和显式因子输入交接。生产 KKT 使用融合映射，因子化继续使用原输入接口。影响正规方程和 KKT 的调用边界。验证通过 [Normal 回归](../tests/test_normal_cholesky.cpp)及 IPM 内核测试。

## CHOLMOD 装配与符号结构

- 类型为线性代数实现。为减少矩形 AAT 的无效装配和建立符号图的开销，使用 [私有 CHOLMOD 数值入口](../third_party/cholmod/aat_suffix.cmake)、[AAT 结构](../src/cholmod_aat_pattern.hpp)及[正规方程符号图](../include/solver/detail/normal_gram_pattern.hpp)。影响正规方程装配、容量检查和 CHOLMOD 构建。验证通过 Normal 回归及 IPM 内核测试。

## FactorHiGHS 符号隔离

- 类型为构建修复。为避免静态链接选入同名上游实现，在 [私有内核构建](../third_party/factorhighs/build.cmake)与 [生产包装层构建](../CMakeLists.txt)隔离命名空间。影响私有分解内核链接。现有 Release 构建检查通过，分块 LDL 和后端回归通过。

## 冷启动有界单纯形

- 类型为新增后端。为给连续 LP 提供独立的冷启动路径，[单纯形求解器](../src/simplex.cpp)由[逻辑基](../include/solver/detail/logical_basis.hpp)启动，在需要时用零目标恢复原始可行性，再在同一基上继续原目标，并对增量更新执行数值复核。影响 [后端分发](../src/highs_backend.cpp)、[CLI](../src/main.cpp)与 CMake 构建。验证通过 [冷启动单纯形组件](../tests/test_cold_simplex.cpp)、后端及 CLI 回归测试。

## 回归覆盖与实验工具

- 类型为测试与工具。为通过标准入口复核数值实现与报告，正式 [CMake](../CMakeLists.txt)注册 [IPM 内部组件](../tests/test_ipm_kernel.cpp)、[联立核](../tests/test_ipm_coupled.cpp)和单纯形组件，并更新 [CLI 回归](../tests/test_cli.py)。新增 [LP 协议重放](../scripts/replay_lp_protocol.py)和独立的 [Normal 搬运微测](../scripts/normal_input_exchange_benchmark.cpp)、[结果分析](../scripts/analyze_normal_input_exchange.py)。本次 Windows Release 构建检查通过，CTest 21/21 通过。本次同步未执行独立微测、公开 LP 性能评估或协议重放。
