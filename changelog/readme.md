# 变更记录规范与索引

[返回项目总索引](../readme.md) · [代码变更记录义务](../AGENTS.md)

## 记录方式

- 按任务日期使用 `YYYY-MM-DD.md` 命名；同一天的变更追加到同一文件，使用独立标题区分每项变更。
- 每条记录包含：修改类型、修改原因、修改内容、影响范围和实际验证结果。修改内容链接到相关文件，涉及规范时只引用其权威正文。
- 代码包括源代码、脚本、测试代码和影响程序行为的配置。一个任务含有多个独立代码变更时，逐项记录，确保全部覆盖。
- 验证结果写明实际执行的检查与结论；未执行时写明原因和剩余限制。
- 新建日期文件时，在下方索引添加链接，按日期倒序排列。文档初始化等有意义的文档变更也可以记录。
- 历史条目保留事件信息；当前规则和设计结论通过链接引用，遵循 [知识治理规范](../knowledge/governance.md)。
